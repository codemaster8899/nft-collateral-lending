# Crypto / NFT Lending Platform

A crypto lending platform where users can borrow against NFTs, create collection offers, accept loan requests, and manage active loans.

## Tech Stack
- Frontend: Next.js, React, TypeScript, wagmi, React Hook Form
- Backend: Node.js, Sequelize, MySQL/PostgreSQL
- Web3: ERC20 approvals, wallet signatures, smart contract interactions
- Integrations: OpenSea, SimpleHash, AWS S3, Twitter API, email notifications

## Key Features
- NFT-backed borrowing flow
- Collection-based loan offers
- Wallet authentication and message signing
- ERC20 balance and allowance checks
- Loan lifecycle management
- NFT metadata refresh
- Email and push notifications
